# Distraction-free Notepad

A single-page writing pad with nothing else on the screen. Open `index.html` in a browser and start typing.

## Bullet lists

Lists are driven by the backtick (`` ` ``) key:

- Long-press `` ` `` to start a list
- Short-press `` ` `` on a bulleted line to add the next bullet
- Long-press `` ` `` on a bullet to indent it
- `Esc` goes back one level, and exits the list at the top level

Up to 5 levels of nesting. Outside a list, `` ` `` just types a backtick.
